说明

这是一个 25M 参数的 base 模型（不是指令微调模型），在 SkyPile 中文网页 + FineWeb-Edu 英文网页清洗后的约 5 亿 tokens 上预训练。 它的能力上限很低：能续写、能模仿文本风格，但不会真正“回答问题”。页面把模型、分词器和推理全部放在浏览器里运行，不需要后端。

架构：Llama 风格（RMSNorm + SwiGLU + RoPE + GQA），8 层，d=384，6 头，2 个 KV 头，上下文 512。
